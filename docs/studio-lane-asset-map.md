
# Studio lane asset map

Shared asset direction for the activated Studio lanes:

- Loyalty Lane Apparel: product cards, patch drops, garment mockups, size/fit disclosure blocks, and checkout-gated CTA art.
- Lingo Wash District: neighborhood map panels, clean-route badges, partner banner frames, and local mission icons.
- Kottons Code Spades: family-safe table art, educator badges, no-chat icons, and turn-state animations.
- Uhno: original color-card table visuals, discard glow, safe-room labels, and moderation overlays.
- Promotion banners: every paid/sponsored slot must be visually labeled and must not load third-party trackers by default.
- Sounds: ship as user-triggered cues only; no autoplay.
- Motion: every animation needs a reduced-motion fallback.
